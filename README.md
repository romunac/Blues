# Moody Blues

**Academic concept for emotion tracking | Conceito acadêmico de acompanhamento emocional**

Moody Blues explores how a mobile application can combine user input and facial-expression analysis to help people track emotional states over time. This is an academic concept, not a clinical or diagnostic tool.  
O Moody Blues explora como um aplicativo móvel pode combinar informações fornecidas pela pessoa e análise de expressões faciais para acompanhar estados emocionais ao longo do tempo. É um conceito acadêmico, não uma ferramenta clínica ou de diagnóstico.

## Technology stack | Tecnologias

- **Flutter** — mobile application interface | interface do aplicativo
- **Python** — processing and analysis | processamento e análise
- **DeepFace** — facial-expression analysis | análise de expressões faciais
- **Firebase** — backend and data services | backend e serviços de dados

## Project goals | Objetivos

- Record user-reported emotional states. | Registrar estados emocionais informados pela pessoa.
- Experiment with facial-expression analysis using computer vision. | Experimentar análise de expressões faciais com visão computacional.
- Explore integrating a mobile app, Python processing, and cloud services. | Explorar a integração entre aplicativo móvel, processamento em Python e serviços em nuvem.
