# Moody Blues

A conceptual application for emotion monitoring and analysis, developed as a Computer Engineering project.

## Overview

Moody Blues explores how a mobile application can combine user input and facial-expression analysis to help track emotional states over time.

## Technology Stack

- Flutter — mobile application interface
- Python — processing and analysis
- DeepFace — facial-expression analysis
- Firebase — backend and data services

## Project Goals

- Provide a simple interface for recording emotional states.
- Experiment with facial-expression analysis using computer vision.
- Store relevant application data in a cloud backend.
- Explore the integration of mobile development, Python and artificial intelligence.

## Architecture

```text
Flutter App
    │
    ├── User Interface
    ├── Emotion Capture
    │
    └── Python / DeepFace
             │
             └── Emotion Analysis
                     │
                     └── Firebase
```

## Status

Concept / academic project. The repository serves as a record of the project's architecture, technologies and development work.
